Projeto Integrador I

O objetivo deste projeto é produzir a documentação técnica e gerencial do sistema Pontuaê, bem como desenvolver um protótipo funcional que permita validar os conceitos, fluxos e requisitos levantados, servindo como base para as fases subsequentes de desenvolvimento do sistema. 
 
O projeto Pontuaê, em sua etapa atual, é composto pelas atividades de especificação, modelagem e prototipação do sistema de gamificação acadêmica. Seu escopo abrange a produção dos artefatos de documentação e a construção de um protótipo navegável que representa as principais funcionalidades do sistema.
